# SourceGit – Personal UI Fork

This is a personal fork of
[SourceGit](https://github.com/sourcegit-scm/sourcegit) with a small set of UI changes to preserve the layout and workflow I prefer.

For the original project, documentation, features, downloads, and support, please visit the [official SourceGit repository](https://github.com/sourcegit-scm/sourcegit).

## Changes

Compared to upstream, this fork does really only:

- "Revertes" the new side bar and adds back the original view selectors.
- Hides the Git Flow toolbar button.
- Moves the repo settings button back to the repository tool bar.
- Swaps the staged and unstaged panes.
- Shows the current active tab in the `Tabs` dialog.

## Upstream

This fork is kept as close to upstream as possible.

No additional features or functional changes are intended. The changes are limited to personal UI and layout preferences to minimize conflicts with future upstream updates.
